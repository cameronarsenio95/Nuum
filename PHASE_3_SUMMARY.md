**Key Highlights:**

### Critical Schema Rule: ad_sets is the Metrics Source
```typescript
/**
 * TABLE: ad_sets
 *
 * IMPORTANT:
 * - All campaign revenue/costs come from aggregating ad_sets
 * - performance_metrics.costBreakdown contains detailed cost breakdown
 * - spend = total costs for this ad set
 * - revenue = total revenue generated by this ad set
 *
 * DO NOT add revenue/spend columns to campaigns table!
 */
```

### Workspace Scoping
```typescript
/**
 * WORKSPACE SCOPING:
 * Most queries MUST filter by workspace_id. The frontend assumes:
 * - All campaigns belong to a workspace
 * - All creators belong to a workspace
 * - All tasks belong to a workspace
 * - All content_media belongs to a workspace
 * - All notes belongs to a workspace
 */
```

### Trial Duration
```typescript
/**
 * TRIAL DURATION:
 * Workspaces created with plan='trial' should have:
 * - trial_ends_at = now() + interval '14 days'
 * This is set by create_workspace_with_owner RPC function
 */
```

```typescript

supabase.from('creators').delete().eq('id', creatorId)
```

## ⚠️ Important Database Schema Notes

### 1. Metrics Source: ad_sets Table
```
❌ DO NOT add revenue/spend columns to campaigns table
✅ All metrics are calculated from ad_sets

Campaign metrics = SUM(ad_sets WHERE campaign_id = X)
Creator metrics = SUM(ad_sets WHERE creator_id = Y)
Platform metrics = SUM(ad_sets WHERE platform = Z)
```

### 2. Cost Breakdown
```typescript
ad_sets.performance_metrics = {
  costBreakdown: {
    creator_fee: number,
    production: number,
    ad_spend: number,
    other: number
  }
}

ad_sets.spend = total of all cost breakdown items
```

### 3. Workspace Scoping
```
Every query MUST filter by workspace_id:
  .eq('workspace_id', workspaceId)

Or via join:
  .eq('campaign.workspace_id', workspaceId)
```

### 4. Trial Duration
```
New workspaces:
  plan = 'trial'
  trial_ends_at = now() + 14 days
  subscription_status = 'active'

After trial expires:
  plan = 'free'
  subscription_status = 'frozen' (if no payment)
```

### 5. Platform Values
```typescript
ad_sets.platform ENUM:
  'META'      // Facebook & Instagram
  'TikTok'
  'Google'
  'Snapchat'
  'Other'
```
